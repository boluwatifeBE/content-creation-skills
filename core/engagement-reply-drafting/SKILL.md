# Engagement Reply Drafting

Drafts replies to comments and DMs the user has actually received, in their confirmed voice. This is a smaller, more reactive skill than the ones that produce original posts, replies are shorter, more conversational, and responding to someone else's words rather than starting from a topic.

## Before drafting

Confirm `creator-context` is active for house style and persona. If the user's content goals include community or network/relationships, this skill is directly serving those, worth keeping in mind when deciding how much effort a reply deserves, a thoughtful reply is often where those goals actually get built, more than the original post itself.

Get the actual comment or DM text, don't work from a paraphrase of what someone said.

## Reading the incoming message first

Before drafting a reply, identify what kind of message this actually is, since the right response differs a lot by type:

- **Genuine question**: answer it directly and helpfully, this is a real opportunity to demonstrate expertise
- **Agreement or compliment**: a short, warm acknowledgment, don't over-write a reply to something that just needs a genuine "thank you" plus maybe one added thought
- **Disagreement or pushback**: engage with the actual substance of the disagreement, don't be defensive or dismissive, and don't cave immediately either if the user's original point was sound, a good-faith reply can hold a position while remaining respectful
- **Business inquiry or potential lead**: treat this differently, this may need a more careful, considered reply than a casual comment would, flag it as a potential lead so the user notices it, rather than drafting a throwaway reply to something that matters
- **Spam, trolling, or bad-faith engagement**: don't draft an engaged reply to something not worth one, note that this looks like spam/bad-faith and suggest ignoring or a minimal response, rather than crafting a thoughtful reply to a message that doesn't deserve one

## Sensitive or risky replies

If a comment touches something genuinely sensitive, a complaint, a controversial disagreement, something that could become a public back-and-forth, flag this to the user before drafting a reply, and ask how they want to handle it (engage publicly, address privately, or not respond at all), rather than drafting a confident public reply to something that might be better handled differently. This is a case where getting the judgment call wrong has more visible consequences than most other content in this system, a bad reply is public and attached to the user's name in a live conversation.

## Draft-or-generate checkpoint

Ask whether the user wants a fully drafted reply ready to post, or just a starting point/direction they'll finish themselves. Some people want to write their own replies but want a sense of the right angle first, others want the reply ready to paste.

## Batches

If the user pastes in multiple comments at once, handle each individually rather than writing one generic reply style for all of them, comment type varies within a batch (a question next to a compliment next to spam), and each deserves the treatment above. Present replies grouped and labeled by which comment they respond to.

## Voice in replies

Apply the confirmed house style, but recognize replies are inherently more conversational and shorter than posts, the full formatting model (hook, multiple paragraphs, closing question) usually doesn't apply to a two-sentence reply. Per the per-piece flexibility principle, the format here is genuinely different by default, not a deviation to flag each time, a reply reads more like natural conversation than a mini-post. The banlist and tone still apply regardless of length.

## Presenting the result

Present replies as plain text, ready to paste, labeled by which comment or message each responds to. For anything flagged as sensitive or a potential lead, say so clearly before the drafted reply, so the user notices it rather than scrolling past.
